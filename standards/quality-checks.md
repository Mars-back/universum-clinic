# Власні стандарти та перевірки

## Стиль

JavaScript ES modules, import/export, два пробіли, одинарні лапки,
крапки з комою, UTF-8/LF. Оформлення задає Prettier.
У коді застосунку SQL міститься тільки в repository та database; значення передаються через ?.
Service перевіряє поля, controller обирає HTTP-відповідь.

## Формат spec та ADR

spec: мета і межі → компоненти → взаємодія → дані й ER →
ключові сценарії (ініціатор, зміна, результат) → приймання.
ADR у форматі MADR: статус/дата → контекст → критерії → варіанти →
рішення → наслідки → підтвердження. Один файл описує одне ключове рішення.

## Перевірки

| Команда                    | Призначення                                               |
| -------------------------- | --------------------------------------------------------- |
| npm run format             | Виправляє оформлення                                      |
| npm run format:check       | Перевіряє оформлення                                      |
| npm run lint               | Шукає типові помилки JavaScript                           |
| npm run build              | Перевіряє синтаксис server.js                             |
| npm run test:smoke         | Перевіряє реальний /health                                |
| npm test                   | Перевіряє створення, списки, FK, дату і кількість таблиць |
| npm run check / make check | Усі перевірки послідовно                                  |

У hooks викликається npm run check. && зупиняє конвеєр на першій помилці.
Перед commit додай всі потрібні зміни через `git add .`.
