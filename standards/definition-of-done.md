# Definition of Done

- Ідея й команди запуску описані в README.
- Пакети відтворюються через npm ci.
- Працюють створення та списки для пацієнтів, лікарів і прийомів.
- У SQLite рівно три таблиці; дані зберігаються після перезапуску.
- Неправильні поля, дата й відсутній зв'язаний запис повертають 400.
- npm run check проходить; hooks підключені.
- Практично перевірено, що помилка блокує commit.
- Є spec, ER, ADR, власні стандарти та аудит.
- Feature-гілка пройшла PR → merge.
